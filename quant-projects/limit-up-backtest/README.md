# 连板竞价策略回测

> A股短线策略研究：基于「连续涨停 + 竞价放量」的次日超额收益假设，完整的回测框架与归因分析。

## 策略核心逻辑

```
选股(T日, 3条件同时满足):
  1. T-1日连续涨停>=2板 (主板10%涨停), 非ST, 主板股票
  2. T日集合竞价成交额 >= 2 * T-1日竞价成交额, 且 > 3000万元
  3. T日开盘涨幅 >= 4%

情绪闸门: T-1日 ADJS >= 0 (市场情绪好才交易)

两档买点:
  档1: 情绪好 + 低开 (<0%)      → 次日开盘买入
  档2: 情绪好 + 一字板 (>=9.8%) → 次日开盘买入

卖出: T+1日收盘卖出 (最优持有周期)
```

## 核心成果

| 指标 | 全样本(287笔) | 组合(33笔) |
|------|-------------|-----------|
| 胜率 | 50.7% | **66.7%** |
| 均值收益 | +0.68% | **+3.07%** |
| 最佳档位 | — | 档1低开: 87.5% / +7.50% |

> 组合 = 情绪好 + (低开 ∪ 一字板)，通过情绪闸门过滤掉噪音信号

## 文件说明

| 文件 | 说明 |
|------|------|
| `backtest_v1.py` | 回测主程序：信号生成 → 买入模拟 → 卖出模拟 → 绩效汇总 |
| `combo_strategy.py` | 组合策略测算：情绪闸门 + 两档买点 + 统计输出 |
| `generate_report.py` | 报告生成器：自动输出Markdown格式的完整回测工作文档 |

## 回测工作文档

完整回测报告见 `README.md`（由 `generate_report.py` 自动生成），包含：
- 数据源与覆盖范围（含覆盖断层诚实记录）
- 策略定义与买点
- 全样本回测结果（分月/分桶/分情绪）
- 组合策略结果（33笔明细）
- 数据质量与局限

## 关键技术点

- **信号工程质量**: 基于已收盘K线计算信号，杜绝重绘
- **情绪指标ADJS**: 市场级情绪指数，T-1日数据，无未来函数
- **多口径对比**: 挂单买入 vs 开盘价买入，T+1开盘卖 vs 收盘卖 vs 持有
- **诚实记录局限**: 未扣手续费/滑点、数据断层(3~7月仅58%覆盖)、样本量偏小
